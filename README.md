# Dophuc AI — Trợ lý AI tiếng Việt

Ứng dụng chat AI triển khai trên Cloudflare Workers + Workers AI. Giao diện tiếng Việt, lịch sử chat phía trình duyệt, endpoint API `/api/chat`.

## Cài đặt
1. `npm install`
2. `npx wrangler login`
3. `npx wrangler deploy`

Xem `wrangler.toml` để cấu hình Workers AI. Dự án được tạo mới lấy cảm hứng từ trải nghiệm chat AI; không sao chép nguyên văn mã nguồn bên thứ ba.
